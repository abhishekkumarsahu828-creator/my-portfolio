# Personal Portfolio

A modern, responsive multi-page personal portfolio website built using HTML, CSS, and JavaScript.

## 🚀 Live Demo

Coming soon...

## 📌 About

This portfolio showcases my skills, projects, programming knowledge, and contact information.

The website was built as a learning project while practicing frontend web development.

## ✨ Features

* Responsive multi-page design
* Home page
* About page
* Skills page
* Projects page
* Contact page
* Dark / Light mode
* Mobile navigation
* Active navigation indicator
* Scroll reveal animations
* Typing effect
* Project category filtering
* Dynamic project cards
* Scroll progress indicator
* Back-to-top button
* Contact form validation
* SEO-friendly page structure
* Accessible navigation and form elements

## ▶️ Run Locally

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Move into the project:

```bash
cd myPortfolio
```

Then open `index.html` in a browser.
